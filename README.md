# Number Guessing Game

## Description
A simple Python Number Guessing Game where the player guesses a randomly generated number.The game provides hints and allows multiple attempts until the correct number is guessed.

## Features
- Random number generation
- User input validation
- Unlimited attempts
- East-to-understand Python code

## Technologies used
- Python 3

## How to Run
'''bash
python "Number guessing game.py"
'''
